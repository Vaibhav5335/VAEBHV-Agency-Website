# VAEBHV // Performance Advertising & Growth Studio

A creative strategist notebook & editorial performance advertising agency website built with **React 19**, **TypeScript**, and **Vite**.

## Agency Focus
- **Meta Ads Manager**: Instagram Reels, Facebook Feeds, Advantage+ Shopping (ASC), and server-side Conversions API (CAPI).
- **Google Ads Manager**: High-intent Search, Performance Max (PMax), YouTube Video, and GA4 attribution.
- **ChatGPT & AI Ads Manager**: Conversational search queries, generative prompt discovery, and AI answer engine placements.
- **Direct-Response Creative**: 15–30 fresh hooks monthly, motion design, and rapid testing to stop thumb momentum within 0.8s.

## Project Structure

```text
src/
├── components/          # Reusable tactile editorial UI components
│   ├── CTA.tsx          # Hand-drawn button/link component
│   ├── Footer.tsx       # Studio colophon & navigation
│   ├── HandDrawnArrow.tsx # SVG sketch arrows & annotations
│   ├── HighlightText.tsx # Marker highlighter brush & scribbles
│   ├── Navbar.tsx       # Sticky navigation & mobile drawer
│   ├── ServiceCard.tsx  # Service card with custom SVG doodles
│   └── WorkCard.tsx     # Campaign architecture preview artboards
│
├── data/
│   └── agencyData.ts    # Centralized data model for channels, work & process
│
├── pages/
│   └── Home.tsx         # Master page orchestration
│
├── sections/            # Major landing page sections
│   ├── About.tsx        # Agency manifesto & operator tenets
│   ├── ContactCTA.tsx   # Final audit inquiry statement
│   ├── Hero.tsx         # Hero headline & interactive Strategy Board
│   ├── Process.tsx      # 5-stage systematic account lifecycle
│   ├── Services.tsx     # Full-funnel platform capabilities
│   └── Work.tsx         # Live multi-channel campaign engines
│
├── index.css            # Tactile design tokens, paper grid & typography
├── main.tsx             # Application mount
└── App.tsx              # Root component
```
